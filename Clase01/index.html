GitHub y Control de Versiones

¿Qué es Git?

Sistema de control de versiones que permite:

  • Guardar historial de cambios
  • Volver a versiones anteriores
  • Colaborar sin conflictos

Comandos Principales

git init Inicializa repositorio
git add . Agrega archivos al staging
git commit -m "mensaje" Guarda cambios
git push origin main Sube cambios a GitHub
