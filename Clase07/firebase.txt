// 🔥 CONFIGURACIÓN DE FIREBASE CON REACT
// =======================================
// Este archivo explica cómo conectar un proyecto de React con Firestore paso a paso
// con explicaciones claras para alumnos.

// PASO 1: ENTRAR A FIREBASE
// --------------------------
// 1. Abrir https://firebase.google.com
// 2. Iniciar sesión con una cuenta de Google
// 3. Entrar a la “Consola de Firebase” (Firebase Console)
//    - Aquí se gestionan todos los proyectos y servicios de Firebase

// PASO 2: CREAR UN NUEVO PROYECTO
// --------------------------------
// 1. Hacer clic en “Agregar proyecto”
// 2. Ponerle un nombre descriptivo (ej: e-commerce)
// 3. Desactivar Google Analytics si no lo vamos a usar
// 4. Esperar a que Firebase cree el proyecto
//    - Esto puede tardar unos segundos

// PASO 3: AGREGAR FIREBASE A UNA APP WEB
// ----------------------------------------
// 1. Dentro del proyecto, hacer clic en el icono </> que dice “Web”
// 2. Poner un nombre para la app (ej: react-ecommerce)
// 3. Hacer clic en “Registrar app”
// 4. Firebase mostrará la configuración de la app: un objeto llamado firebaseConfig
//    - Contiene claves como apiKey, projectId, authDomain, etc.
//    - Este objeto es necesario para que tu app React se conecte a Firebase

// PASO 4: INSTALAR FIREBASE EN TU PROYECTO REACT
// -----------------------------------------------
// Abrir la terminal dentro de tu proyecto y ejecutar:
// npm install firebase
// Esto instala la librería oficial de Firebase para poder usar Firestore, Auth y otros servicios

// PASO 5: CREAR EL ARCHIVO DE CONFIGURACIÓN
// ------------------------------------------
// Crear un archivo en src llamado firebaseConfig.js o FirebaseSetup.jsx
// Este archivo se encargará de inicializar Firebase y conectar Firestore
