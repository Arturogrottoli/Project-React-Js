// a un proyecto de React ya creado.

// PASO 1: ENTRAR A FIREBASE
// - Ir a https://firebase.google.com
// - Iniciar sesión con una cuenta de Google
// - Entrar a “Consola de Firebase”

// PASO 2: CREAR UN PROYECTO
// - Hacer clic en “Agregar proyecto”
// - Ponerle un nombre (por ejemplo: e-commerce)
// - Desactivar Google Analytics si no lo necesitamos
// - Esperar a que se cree el proyecto

// PASO 3: AGREGAR FIREBASE A UNA APP WEB
// - Dentro del proyecto, hacer clic en el icono </> “Web”
// - Ponerle un nombre a la app (por ejemplo: react-ecommerce)
// - Firebase mostrará una configuración con las claves del proyecto
//   (esto es lo que se llama firebaseConfig)

// PASO 4: INSTALAR FIREBASE EN REACT
// En la terminal del proyecto React, ejecutar:
// npm install firebase

// PASO 5: CREAR EL ARCHIVO DE CONFIGURACIÓN
// Crear un archivo en src llamado firebaseConfig.js (o FirebaseSetup.jsx)
// y pegar el siguiente código 👇
